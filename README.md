# Resident Evil Creatures (Minecraft 1.20.1 / Forge 47.3.0)

RE1: Zombie (+revive into Crimson Head), Crimson Head, Cerberus, Infected Crow, Hunter, Chimera, Giant Spider, Web Spinner, Neptune, Yawn, Plant 42, Tyrant, Lisa Trevor.
RE2: Licker (blind, ceiling ambush, beta form), Mr. X / Super Tyrant (door-smashing stalker, stagger kneel), G-Birkin (G1 -> G2 -> G3), Giant Alligator, Ivy, Giant Moth, Moth Larva.
RE3: Nemesis (3 forms, rocket launcher, tentacles, door-smashing pursuit), Grave Digger (Yawn serpent rig/behaviour, reskinned), Drain Deimos (Giant Moth rig/behaviour + blood drain, reskinned), Brain Sucker (bat flier, head-cling drain), Pale Head (tanky non-reviving zombie, swollen skull), Hunter Beta (tougher sandy Hunter), Hunter Gamma (amphibious tongue Hunter, Licker rig).
RE4: Ganado (random tool; Plaga bursts into whip / scythe / spider forms), Dr. Salvador (chainsaw, beheading), Garrador (blind, weak back), Colmillos (wolves, Cerberus rig), Novistador (invisible insect, Moth rig), Regenerador and Iron Maiden (regenerating zombie rig), El Gigante (stalker rig, weak back, kneels), Del Lago (Neptune rig, giant).
RE4 (more): Zealot, Armadura, Verdugo (weak to cold), Krauser (bow + knife). RE5: Majini, Chainsaw Majini, Executioner Majini, Kipepeo, Reaper, Adjule, Ndesu, Wesker (super-speed). Most are variants on an existing rig/behaviour (tools/genfam.py, tools/fam_re45.py).
More bosses/variants (RE4-RE6): Saddler, Salazar, Bitores Mendez, Uroboros, Jill, Gatling Majini, J'avo, Ustanak, Napad, Ogroman, Simmons (tools/fam_re456.py).
RE7/RE8: Molded, Fat Molded, Jack Baker, Eveline, Lycan, Lady Dimitrescu, her Daughters, Heisenberg, Moreau, Sturm, Urias, Soldat (tools/fam_re78.py), plus Marguerite, Mother Miranda, Haos, Gnezdo (tools/fam_re678.py).
Spawn eggs for all (creative tab: Spawn Eggs). New creatures: `tools/addentity.py` registers one; see an existing creature for the pattern.

- Build: `./gradlew build` (JDK 17). Run: `./gradlew runClient`.
- Animation: `anim/AnimClip` keyframes (anticipation / impact / follow-through / recovery) added on top of walk/idle in each `client/<creature>/*Model`.
  Each `AttackMove` hit tick matches the clip's impact key (`hitTick/duration`).
- Textures are generated: `python3 tools/tex_*.py` (UVs are parsed from the model sources by `tools/autotex.py`).
- Creative tabs: one per game (Resident Evil 1 .. Village) with that game's spawn eggs.
- Dev: `/rmove <id>`, `/rform <n>`, `/rstop` (dev runs only) play a move of the nearest creature for animation review.
- Checks: `tools/jc.sh` fast javac; dev GameTests in `com.reevil.gametest` (`/test runall`, excluded from the jar);
  `tools/ModelCheck.java` bakes every model and verifies clip bones.
- Voices: six synthesised archetypes (groan/growl/hiss/roar/screech/squelch; `tools/synth_sounds.py`, layered on top of the vanilla sounds by `BioMonster.playVoice`). Replace the .ogg files in `assets/reevil/sounds/voice/` to use your own.
- Natural spawning: `data/reevil/forge/biome_modifier/*.json` (bosses excluded).

## Structures & factions
- `tools/gen_structures.py` generates 8 natural structures (Spencer Mansion/forest, Raccoon City/plains, Salazar Castle/mountains, Ganado village/taiga, Majini village/desert-savanna-badlands, Baker house/swamp, Dimitrescu Castle/snow, Edonia ruins/jungle) with spawners + structure spawn overrides for that game's creatures. Test: `/place structure reevil:<name> x y z`, `/locate structure reevil:<name>`.
- Factions (`entity/Factions.java`): same origin = allies, different origin = enemies, all non-mod mobs hostile both ways (`FactionEvents`). Edit `ALLIES` for confirmed alliances.
- `tools/variantgen.py`: gives reskinned creatures their own silhouette (adds/replaces cubes on the parent rig so clips keep working, paints the new cubes into an extended texture). Edit a spec there and run `python3 tools/variantgen.py <id>`.
- Remake edition: `tools/variants_remake.py` (17 creatures `re1r_/re2r_/re3r_/re4r_*`, own tabs re1r..re4r) + 5 remake structures (`spencer_mansion_remake`, `raccoon_police_station`, `raccoon_downtown`, `village_remake`, `salazar_castle_remake`) in `gen_structures.py`.
- Remake-only moves: `tools/remake_moves.py` (authoring in ticks -> entity overrides + `client/remake/RemakeClips.java`), regenerated by `tools/variants_remake.py`. Extra moves use ids 30+ and merge into the parent's move list via `RemakeMoves.merge`.
- Canon extras: `tools/canon_moves.py` generates `entity/CanonData.java` (extra moves ids 40+, mutations, regeneration via `CanonMoves`), `client/canon/CanonClips.java` and `CanonVisuals.java` (mutation parts shown by `BioMonster.getMut()`). `BioMonster.allMoves()` = moves() + canon extras.
- Canon audit (wiki-verified, see `tools/CANON_NOTES.md`): `tools/rework_entities.py` (re-parent/re-dimension), `tools/variants_canon.py` (models), `tools/canon_moves.py` (moves/mutations). Run order: `rework_entities.py` -> `variants_canon.py` -> `canon_moves.py`. J'avo mutations are a bit-packed slot system in `BioMonster.getMut()`.
- Character bodies: `tools/variants_char.py` (Krauser, Saddler, Mendez, El Gigante, Ogroman, Executioner, Wesker, Jill, Simmons, Dimitrescu). Full regenerate order: `variantgen.py`, `variants_canon.py`, `variants_char.py`, `variants_remake.py`, `canon_moves.py`.
- `BioMonster.retarget()`: creatures switch to whoever is hitting them / a closer enemy instead of chasing a far target.
- Canonical sizes: `tools/sizes.py` -> `entity/CreatureSizes.java` (hitbox + extra render scale; heights from the wiki where given, e.g. Dimitrescu 2.9 m, Ogroman 30+ ft, El Gigante ~4x human).
- Config `config/reevil-common.toml`: `factionHostility`, `smartRetarget`, `drops`, `damageScale`. Creatures drop vanilla loot by toughness (`CanonEvents`). Game tests tag mobs `reevil_iso` so neighbouring test cells do not fight.
